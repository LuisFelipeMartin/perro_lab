Desconectado
📋 Instrucciones de Uso
  1. Conectar: Presionar Conectar y seleccionar PerroRobot_ESP32 (un solo dispositivo conectado a la vez).
  2. Desconectar: Desvincula el Bluetooth del perro de forma limpia.
  3. Parada de Emergencia: El botón ¡DETENER TODO! frena inmediatamente los motores.
  4. Animaciones Continuas: Activa o desactiva las animaciones cíclicas de Cola, Rotar Cuello o Asentir (Inclinación).
  5. Posturas Estáticas: Permite fijar poses directas como Ladear (Izq/Der) y Mirar (Izq/Der). Para volver a la posición neutra pulsa Centrar Cabeza.
💡 Requisitos: Conexión Wi-Fi para cargar la aplicación web y fuente externa de 5V bien conectada para alimentar los motores.
