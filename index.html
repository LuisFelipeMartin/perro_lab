Desconectado
📋 Instrucciones de Uso
  1. Conectar: Presionar Conectar y seleccionar PerroRobot_ESP32.
  2. Desconectar: Desvincula el Bluetooth de forma limpia.
  3. iOS (iPhone/iPad): Debes abrir esta web dentro de la app gratuita Bluefy.
  4. Parada de Emergencia: El botón ¡DETENER TODO! frena inmediatamente los motores.
  5. Animaciones Continuas: Activa o desactiva los movimientos cíclicos de Cola, Rotar Cuello o Asentir.
  6. Posturas Estáticas: Posturas fijas como Ladear o Mirar. Pulsa Centrar Cabeza para regresar a la posición neutra.
  7. Control Individual: Ajusta libremente el ángulo directo de cada servo (10° a 170°).
💡 Requisitos: Conexión HTTPS para Web Bluetooth y fuente externa de 5V conectada a la bornera verde del driver.
